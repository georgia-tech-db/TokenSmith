## Redistribution Policy for Third-Party Test Materials

Third-party educational materials without explicit, documented public redistribution permissions (such as proprietary textbook chapters, restricted conference proceedings, or university lecture slides) must not be bundled directly in this repository.

For test suites that require copyrighted third-party resources:
1. Provide an authoritative public URL reference in this directory or test script.
2. Allow users and CI runners to fetch their own local copies on demand into a non-tracked local cache directory.
