TokenSmith 0.1.14 makes it easier to follow an explanation, read its sources, and keep studying while an answer is being prepared.

## Study Chat

- Highlight part of a question or answer and choose **Ask about this**. The selected passage stays attached to your question instead of being pasted into the draft.
- Ask for a simpler explanation and compare it with the original answer.
- Read answers as soon as they are ready, while suggested follow-ups finish separately.
- See generation status, elapsed time, and estimates informed by recent runs. Stop a request from Chat, Library, or Settings without losing the completed answer.
- Switch screens while a response is running without losing the draft or pending request.
- Improved handling of math delimiters and currency, plus five text-size choices throughout the app.

## Source Reading

- Open the first retrieved source while waiting for an answer, when Show Sources is enabled.
- Move between PDF, Markdown, and text sources without closing the reader.
- Use the Markdown table of contents to jump between sections, then return to the cited passage.

## Models And Search

- Updated device-aware Gemma recommendations, with lighter alternatives and existing model selections preserved.
- Tighter context checks and an optional Thinking setting for Ollama Gemma 4 E4B. Unfinished responses now report a length-limit error instead of appearing complete.
- GPU acceleration is enabled by default for Ollama embeddings. Turn it off in Application Settings to use the CPU for document indexing and search; chat models are unchanged.
- Removed the unused direct-GGUF backend and its obsolete settings. Local models run through Ollama; cloud chat models remain available.

**Upgrade note:** Legacy direct-GGUF model records, identifiable associated chats, and collection indexes are removed. Original documents and Ollama downloads are kept. Re-add affected collections with an Ollama or remote embedding model.

## Project Checks

- Automated build, unit-test, integration, and real Nomic hybrid-retrieval checks, with CI and separate TypeScript/Python coverage badges.
- Benchmark details show the question, reference answer, and retrieved evidence. These checks measure retrieval coverage, not generated-answer accuracy.
