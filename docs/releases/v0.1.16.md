TokenSmith 0.1.16 adds an Intel Mac installer and topic-based Practice with visible mastery progress.

## Mac installers

- Separate DMGs are available for Apple Silicon and Intel Macs. The Intel version requires macOS 15 or newer.
- Both installers are built and tested on native Mac runners, including installer integrity, app signatures, and document-search runtime checks.
- Simplified DMG creation and added checks that prevent packaging mismatched app and runtime architectures.

## Practice and mastery

- Choose topics within chapters and see a compact overview of your estimated mastery and practice coverage.
- Answer True/False questions grounded in passages mapped to the selected topic. Sessions rotate through those passages and allow two questions per passage; previous questions are included when preparing another question from the same passage to discourage repetition.
- See source passages while a question is being prepared and before answering. Reading sources no longer marks an answer as having received Chat help.
- Open **View mastery** or **Export practice record** beside **Practice another topic**. Clearing Practice history removes conversations while retaining mastery progress.
- Chat and Practice share more controls, including the materials picker, source reader, and log access.

Mastery is an estimate based on practice responses and generated answer keys, not a grade or a calibrated measure of understanding.

## Library and usability

- Save and reopen collection folders, with document selection shared between Chat and Practice.
- See model-loading progress separately from answer generation.
- Improved dropdown alignment and printed line numbers in code passages.
- Gemma 4 26B is now the default recommended local chat model.

## Upgrading from 0.1.15

The new collection format resets older library references and saved Chat/Practice history rather than migrating them. Model settings are retained; original documents and old index files are not deleted. Re-add your materials in Library after upgrading. Installations already using the new collection format keep their saved state.
