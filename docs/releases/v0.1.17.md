TokenSmith 0.1.17 gives Practice its own pane and makes libraries easier to create, prepare, and share.

## Chat and Practice

- Open Practice from the main navigation and use the same model picker as Chat, including changing models during a session.
- Use **Practice this topic** in Chat to start a new session with that topic and its sources selected. Use **Chat about this question** to discuss a practice question.
- Export practice records through the native save dialog. Topic coverage and completed-session actions are clearer.
- Review one question at a time, choose manual or automatic advancement, and practice several selected topics in one session.
- Read supporting passages in the shared source pane while Chat or Practice prepares a response.

## Libraries and document preparation

- Create a library from a folder or a single PDF, Markdown, or text file. Choose the source first, then confirm its unique library name and preparation options.
- Choose OCR separately from Basic or LLM-Based Chunking. OCR is off by default; Markdown and text files are always read directly.
- Use Rapid OCR or Gemma OCR for scanned PDFs. Rapid OCR shares downloaded recognition models across libraries and reports downloads and model loading separately from page processing.
- Enable topic extraction during preparation or extract topics later from indexed documents. Preparation and topic extraction use the selected model, with Gemma 4 E4B as the default.
- Failed topic responses are retried with specific validation feedback. Saved batches are retained, and topic-only retries avoid repeating document preparation.
- Export portable **.tokensmith** libraries and import them as independent copies, including indexed content, saved topics, and original documents.
- Close libraries to remove them from the current workspace, or delete them from the library list. Original documents and saved library files remain on disk.

## Setup, progress, and readers

- Simplified first-time setup and model controls. Suitable devices are offered Gemma 4 26B A4B; other devices are offered E4B.
- OCR and chunking have separate progress indicators. Remaining-time estimates use minutes or hours for longer tasks and adjust as processing progresses.
- Clearer page, model-loading, and download status; fewer misleading status changes and transient library-update errors.
- PDF pages fit the reader width, page navigation stays together, and changed source lists start at the top when reopened.
- Improved retrieval-query cleanup and handling of focused code, table, and cross-section evidence.

## Validation

Added regression coverage for setup, model downloads and deletion, library lifecycle and archives, OCR choices, topic extraction, and navigation. The release includes native setup and archive checks, real Rapid OCR coverage with cached models, and desktop/mobile interface checks.

Unsent Chat drafts are cleared when switching panes.
