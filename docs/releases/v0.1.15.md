TokenSmith 0.1.15 adds document-focused practice and improves how study chat uses model context and reasoning.

## Study And Practice

- Choose individual documents from your collections and use the same selection in Chat and Practice.
- Practice with questions grounded in your selected materials. Get feedback on your answer, use a hint, view a reference explanation, and revise your response.
- Return to saved practice sessions and review which questions you answered independently or with help.
- Bring a practice question, your answer, and its feedback into Chat for further discussion.

## Reasoning And Model Context

- Choose **Auto**, **Off**, or **On** for reasoning on supported Ollama models. Auto favors direct answers for lookups, summaries, and standard explanations, while retaining reasoning for calculations, worked examples, and other tasks that require deriving a result.
- Retry a completed answer with reasoning and keep the original answer available for comparison.
- Set context size to **Auto** to use limits reported by local and cloud models, or choose **Custom** to set a size within the model's supported limit.
- Ollama context grows to fit the question, sources, and answer allowance without allocating the model's entire supported window for every request. Prompt-size checks can increase the window before dropping source passages.
- Cloud requests honor reported input and output limits. When a provider does not report a context limit, Auto uses an 8K fallback; a Custom size remains available.

**Settings note:** Previously saved 2K and 8K context settings migrate to Auto. Other saved sizes remain Custom, and explicit Auto or Custom selections are preserved.

## Project Checks
